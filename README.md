# The Nature Of Code

This repository is me solving the examples and exercises of The Nature Of Code book.

I decided to learn that book out of interest for Physics, visualizing ideas and
JavaScript.

## My Workflow

Since I use neovim, I decided to use along with it npm to install development dependencies
required for the project, which are typescript definition files for p5.js
for language-definition and syntax-validation.

Then I use a p5.js library from jsdelivr CDN in my index.html so that my browser
renders sketch.js through the internet on my localhost port.

``` bash
python3 -m http.server 8081
```
